# TTGO Camera && TTGO Camera Plus

| Function    | TTGO T-Camera Plus   |
| ----------- | -------------------- |
| MIC         | supported            |
| SDCard      | supported            |
| Charging    | supported            |
| I2C         | supported            |
| Screen      | IPS Panel ST7789/1.3 |
| Camera      | OV2640               |
| PIR         | not supported        |
| User button | not supported        |
| Core        | ESP32-DOWDQ6         |
| PSRAM       | 8MBytes              |
| FLASH       | 4MBytes              |
| UART        | CP2104               |
